浅色主题使用暖金色数字、蓝色资产段和绿色收入，五个页面保持原有 B 布局。正文、小字及语义颜色在主要浅色背景上对比度均达到 4.5:1；日历今天标记与选中日期分别检查。保存外观只改标语和主题配置；系统深浅切换不改任何配置、交易、成本或正式批次。动画中可更新色板，销毁后停止主题及系统偏好监听。

0.1.8 的隔离脚本改为布局就绪后只启用一次插件，避免自动启用和脚本启用产生不同实例；对抗脚本核对视图与检查对象属于同一实例。截图草稿重开检查等待行真正出现后才断言，不以异步打开前的空列表判断失败。README 首页图由独立演示脚本拍摄，使用新标语及虚拟账户、交易、会员成本，不配置 API 或密钥。

## 设置窗口关闭时机

0.1.8 本轮对抗回归仍在关闭设置附近记录3次相同空栈 `illegal access`，业务流程41项通过但最后的零脚本错误检查失败。专项首页／外观及标准界面50项、多币种14项和截图20项均无页面脚本错误；未把这些通过结果作为宿主关闭问题已修复的证据。

0.1.4 初轮快速关闭设置窗口时出现空栈 `illegal access`，但保存和恢复数据均完成；同一快速关闭场景在旧版也可复现。单独等待恢复界面重建后重复八次没有异常。当前实机流程等待设置任务完成后再关窗，另有八轮保存连接、关闭及主题切换检查。Canvas 及观察器已绑定所属窗口；0.1.5 将 ResizeObserver 的尺寸写入推迟到下一帧，多币种完整流程无页面脚本错误。未将快速关闭宿主窗口的异常宣称为彻底修复。使用时请等保存或恢复操作完成后再关闭设置。
