浅色主题使用暖金色数字、蓝色资产段和绿色收入，五个页面保持原有 B 布局。正文、小字及语义颜色在主要浅色背景上对比度均达到 4.5:1；日历今天标记与选中日期分别检查。切换主题不会改配置、交易、成本或正式批次；动画中可更新色板，销毁后停止主题观察。

研发证据保存在开发者本地的 `evidence/`，没有作为源码仓库内容上传，避免混入本机路径、运行环境或未来的私人样本。公开截图全部使用虚拟账户、金额和原文。复现命令见 [开发说明](development.md)。

尚未完成真实 DeepSeek／其他供应商 API 的重复准确率、Typeless、真实中文输入法、人工音效、长期日常记账和跨设备同步验收。本机模拟服务经过插件真实请求接口，但不能代表真实模型的准确率或延迟。GitHub CI 只检查核心、构建和打包。

## 设置窗口关闭时机

本版初轮快速关闭设置窗口时出现空栈 `illegal access`，但保存和恢复数据均完成；同一快速关闭场景在旧版也可复现。单独等待恢复界面重建后重复八次没有异常。当前实机流程等待设置任务完成后再关窗，另有八轮保存连接、关闭及主题切换检查。Canvas 及观察器已绑定所属窗口；未将快速关闭宿主窗口的异常宣称为彻底修复。使用时请等保存或恢复操作完成后再关闭设置。
